# Security policy

Only the latest release gets security fixes.

Please do not report vulnerabilities in a public issue. Use **Report a vulnerability** on the
repository's **Security** tab, which opens a private conversation with the maintainers. Include the
steps to reproduce the problem, the affected version and your OS.

This is a spare-time project, so there is no guaranteed response time.

Release binaries are unsigned. To check a download, compare it against the `SHA256SUMS` file
published with the release.
